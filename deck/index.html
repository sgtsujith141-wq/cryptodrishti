The threat

Harvest now, decrypt later

  • Shor's algorithm breaks RSA, Diffie-Hellman, ECDH and ECDSA outright on a large quantum computer. Key size gives no protection.
  • Grover's algorithm only halves symmetric strength — AES-256 survives.
  • So all public-key cryptography falls, and that is what secures every TLS session, VPN, signature and PKI in the country.
  • An adversary records encrypted traffic today and decrypts it the day a quantum computer arrives. Long-lived secrets are already lost.
2024 NIST published the replacements — FIPS 203, 204, 205. The mathematics is solved.
~0% Of Indian critical infrastructure has migrated. Not because it is hard — because nobody knows what cryptography they have.

The risk model

Mosca's inequality, implemented honestly

X data confidentiality lifetime   Y migration time   Z years to Q-Day

X + Y > Z

Data sealed today is readable by an adversary recording it now. Exposure = X + Y − Z years.

  • Z is genuinely unknown. We model it as a distribution and report a probability, never a date. Any tool that hardcodes Q-Day is bluffing.
  • Every score is a transparent product of named factors, each visible in the interface with its input value. No black box.
  • Findings we cannot resolve are reported as unknown, never guessed.
