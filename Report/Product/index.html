The problem

You cannot migrate what you cannot list.

Shor's algorithm ends RSA, Diffie–Hellman, ECDH and ECDSA. Grover's halves the strength of every symmetric cipher and hash. The migration is not optional and the deadlines are already published.

The harder problem comes first. Before an organisation can replace a single algorithm, it has to know what it is running — and almost none of them do. Cryptography is scattered across source code, vendor binaries nobody can read, certificate stores, configuration files and live ports.

Worse, the clock has already started. An adversary does not need a quantum computer today to benefit from one tomorrow: they record encrypted traffic now and decrypt it when the machine arrives. Any data whose secrecy must outlive Q-Day is already compromised.

How it works

Six sensors, because cryptography hides in six places.

No single technique finds all of it. Each sensor reads a different surface and reports its own evidence — file, line, matched symbol, technique, and a confidence score.

01

Source

Real parsing, not pattern-matching: a full syntax tree for Python, and a curated rule pack for everything else.

49 rules · 9 languages

02

Dependency

Manifests resolved to what cryptography each library can actually perform, not just what the code calls directly.

pip · npm · Maven · Go · Cargo

03

Certificate

X.509 parsed for key type, size, validity and signature algorithm — including the new post-quantum identifiers.

incl. ML-DSA · ML-KEM · SLH-DSA

04

Configuration

What is actually deployed, which is frequently not what the code implies: cipher suites, groups and protocol versions.

TLS · SSH · IPsec

05

Binary

The one most tools skip. Vendor binaries you cannot read still contain the constant tables their algorithms require — and those bytes cannot be hidden without breaking the maths.

8 verified constants · 72 symbols

06

Network

A live handshake against a real endpoint, reporting hybrid post-quantum group support — or honestly saying it could not test.

three-state result

Then it says how bad it is, in years.

Every asset is classified by what a quantum computer does to it, scored, and run through Mosca's inequality against a Q-Day distribution — never a single asserted date.

Broken by Shor

Destroyed outright. RSA, DH, ECDH, ECDSA.

Weakened by Grover

Effective strength halved. AES-128, SHA-256.

Unresolved

Not determinable statically. Reported, never guessed.

Hybrid

Safe if either half holds. X25519 + ML-KEM-768.

Quantum-safe

Believed secure. ML-KEM, ML-DSA, AES-256.

Why every crypto constant was recomputed from first principles

That check found two hex typos in our own reference tables, which would have caused the scanner to report binaries as clean when they were not. A four-byte signature matching thirty-two unrelated system binaries was removed for the same reason.

Standards & environment

Output a regulator can actually consume.

The deliverable is not a screenshot. Every asset is emitted as a CycloneDX 1.6 cryptographic-asset component — the ECMA-424 standard — and validated structurally, live.

Built for the environments that need it most. Nothing in the tool makes an outbound request — no CDN, no web font, no telemetry, no cloud service. It installs inside an air-gapped enclave without an exception request, and the guarantee is demonstrated by unplugging the network cable and carrying on.

The entire third-party supply chain is four packages. For anything seeking accreditation, that is the point rather than a limitation.
