Mosca exposure model

X + Y > Z  →  data sealed today is readable later.

2034

X is how long the data must stay secret. Y is how long migration takes. Z is years until a quantum computer exists. If X + Y is greater than Z, data sealed today is already readable by an adversary recording it now. Nobody knows Z, so it is modelled as a distribution and reported as a probability rather than asserted as a date.
