§2 The clock

Mosca's inequality. Move the estimate and the estate re-ranks against it.

2034

X is how long the data must stay secret, Y how long migration takes, Z the years until a quantum computer exists. If X + Y exceeds Z, data sealed today is already readable by an adversary recording it now. Nobody knows Z, so it is modelled as a distribution and reported as a probability — never asserted as a date.
